# Signal / Self History Connector Privacy Notice

Status: Draft for a future Chrome Web Store submission. This notice does not mean the extension has been published.

## Data accessed

Only after the user selects Approve & transfer and grants Chrome's optional History permission, the extension queries Chrome history items (URL, page title, and last-visit timestamp) whose last visit falls within a period selected in the extension popup. The extension filters to HTTP and HTTPS URLs.

The extension does not access passwords, cookies, authentication tokens, private account APIs, or files. It does not read page contents.

## Data use and transfer

History results are transferred directly to the user's open Signal / Self dashboard page at the configured GitHub Pages origin. The data is processed in that browser tab's memory and is not sent to an AI provider, analytics service, advertising partner, or database. The extension does not persist history records.

## User controls

History permission is optional and may be revoked in Chrome extension settings. The dashboard receiver can be disconnected for the current tab. Closing or reloading the dashboard clears its in-memory records. The user may remove the extension at any time.
